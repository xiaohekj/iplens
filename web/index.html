    关于 IPSpot 检测原理与常见问题

    原生 IP、广播 IP 与家宽判定

    通过对比 RIR 注册局（ARIN / RIPE / APNIC）归属国家与多库物理定位识别原生或广播属性，并融合 ASN 类型、rDNS 与 Shodan/AbuseIPDB 情报精准区分家宽与机房。

    人机流量比与纯净度系数

    接入 Cloudflare Radar 全网近 7 天真实 ASN 人机流量统计，结合网络基线、滥用举报与代理黑名单透明计算风控系数（0–100%）。

    浏览器指纹与隐私泄露检测

    集成 FingerprintJS v4、Canvas/WebGL/Audio/字体硬件指纹，以及 32 位随机子域 DNS 泄露与多 STUN WebRTC 泄露排查。

    IP 真实地理位置与开放 API

    基于目标 IP 坐标通过 OpenStreetMap 反查同区真实街道、城市、州省、邮编与时区，并提供免鉴权 JSON API 供开发者调用。
