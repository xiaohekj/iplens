    关于 IPSpot 检测原理与常见问题

    8 项问答

    通过对比 RIR 注册局（ARIN / RIPE / APNIC）与 RDAP 归属国家及 12 源物理定位识别原生或广播属性，并结合 ASN 类型、云厂商关键词、rDNS 反向解析与 Shodan 特征精准区分原生家宽、双 ISP 与机房 IP。

    接入 Cloudflare Radar 近 7 天 ASN 全网真实人机请求占比，结合网络基线、跨区广播、代理/VPN/Tor、AbuseIPDB 与 StopForumSpam 举报记录透明加权计算 0–100% 风险值与纯净分，且不对大网家宽误伤。

    每项风险信号均由 proxycheck.io、Tor 官方 Onionoo 节点库、StopForumSpam、IP2Location、ipquery.io、ip-api.com 与 Shodan 开放端口并行核验，并在卡片中直接列出实际参与核验或命中的数据源。

    各家 GeoIP 数据库（MaxMind、IP2Location、IPInfo、ipapi.is、GeoJS 等）更新周期与任播/广播收敛策略不同。IPSpot 同屏聚合最多 12 个独立地理库并以共识算法定位，避免单库偏差误判。

    本地浏览器集成 FingerprintJS v4 及 Canvas、WebGL、Audio、字体、屏幕缩放与 WebDriver/Headless 自动化特征采集，并与出口 IP 的国家、时区、语言和 WebRTC 实时交叉比对一致性。

    DNS 泄露通过 32 位高随机子域名探测绕过本地与运营商缓存，捕获真实出口递归解析服务器；WebRTC 泄露则并发连接多组国际 STUN 节点，排查浏览器是否绕过代理暴露真实公网 IP。

    根据目标 IP 经纬度坐标，通过 OpenStreetMap Nominatim 与 Photon 逆地理编码服务实时反查同区域真实存在的街道、城市、州省、国家、邮编与时区，支持点击“换一个同区地址”及一键复制。

    ASN 监控直连 RIPE RIS Live 监听全球实时 BGP 路由宣告与撤销；AI 诊断基于真实检测结果输出业务可用性建议；开放 API 支持免鉴权传入 IP、域名或 ASN 查询结构化 JSON 数据。
