DNS LEAK TEST

DNS 泄露检测

检测你的 DNS 解析请求实际由哪些递归服务器完成。使用代理 / VPN 时，若解析仍由本地运营商完成，会暴露你的真实位置。

原理：多次请求 edns.ip-api.com 检测端点，每次跳转至全新随机子域，其权威 DNS 记录解析该子域的递归服务器并随响应回传（基于 EDNS Client Subnet）。
